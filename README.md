## 💡 Projects

### 🖼️ Semantic Image Retrieval System

* Developed a scalable semantic search pipeline for large-scale image retrieval using OpenCLIP embeddings and ChromaDB vector storage.  
* Engineered an asynchronous ingestion system leveraging SQL dump processing and recursive CTE-based extraction to efficiently process 100K+ Wikimedia images.  
* Designed the system to support LLM-integrated workflows through metadata-aware retrieval and context-ready outputs.

---

### 🤖 DocBot — AI-Powered Document Assistant

* Architected and developed a Retrieval-Augmented Generation (RAG) system enabling natural language interaction with documents.  
* Implemented semantic search using FAISS vector indexing and OpenAI embeddings, improving contextual response accuracy and reducing hallucinations.  
* Built backend services in Python Flask for document ingestion, vector processing, and LLM orchestration.

---

### 🚦 Traffic Density Analysis & Green Corridor System

* Implemented a threshold-based traffic signal timing optimization system using a round-robin scheduling approach, where signal durations were dynamically adjusted based on vehicle density to reduce congestion in high-density urban environments.  
* Developed a green corridor mechanism that detects emergency vehicles in specific lanes and prioritizes their movement by dynamically clearing traffic signals along the route.  
* Leveraged TensorFlow, OpenCV, and YOLO for real-time vehicle detection and traffic flow analysis.

---

### 📋 Project Management Application

* Engineered a full-stack application using Next.js and NestJS supporting task tracking, issue management, and role-based collaboration across multiple users.  
* Designed and implemented modular RESTful APIs using a controller–service architecture with DTO validation, enabling scalable CRUD operations and improving API performance and maintainability.  
* Built secure authentication and authorization mechanisms using JWT, and designed relational data models with Prisma ORM and PostgreSQL to support structured multi-entity workflows.
